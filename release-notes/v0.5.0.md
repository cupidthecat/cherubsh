# CherubSH 0.5.0

CherubSH 0.5.0 adds a reproducible compatibility gate for 88 real-world Bash and POSIX shell projects. It also fixes the shell differences found while building that gate.

## Real-world program coverage

- `large-scripts.lock` pins all 88 projects to exact commits. The parser gate checks 6,044 selected shell files against Bash 5.3.15 without executing fetched code.
- `program-smoke.lock` records one reviewed command, source operation, or interactive startup fixture for each project. All 88 fixtures pass.
- The execution runner uses a networkless Bubblewrap namespace with temporary home and work directories. Repository content and Git object stores are read-only.
- Live installers, VPN configuration, certificate issuance, backups, and deployments are outside this matrix. They require disposable machines and the relevant external tools.

## Compatibility fixes

- The parser now handles single-quoted backslashes, `case` blocks inside command substitutions, adjacent arithmetic parentheses, and continued control operators more like Bash.
- Pathname expansion accepts quoted absolute prefixes and trailing slashes. Assignment status now ignores literal command-substitution text while preserving the status of real substitutions.
- Tab-stripped here-documents keep their trailing blank line. Repeated `read` calls no longer consume buffered input too early, and noninteractive `bind` prints Bash's warning.
- Large function bodies no longer trigger the previous slow reader path. PTY tests now wait for the next prompt before submitting a following command.

## Test and CI coverage

- The hardening workflow runs the 6,044-file parser gate and the 88-project execution matrix on every requested hardening run.
- The workspace passes under AddressSanitizer, including the C Readline and History clients.
- Native x86-64 and AArch64 parity jobs pass the full suite. The Oils gate covers 2,804 cases with 2,343 exact matches and 461 reviewed mismatches.
